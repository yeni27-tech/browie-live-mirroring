📖 Petunjuk admin — cara mengisi data

Setiap selesai live (±3 menit)

  1. Shopee: buka Seller Centre → Live Streaming → klik sesi yang baru selesai → Tinjauan Data. Screenshot seluruh kotak angkanya.
  2. Instagram: buka Instagram → profil → live yang baru selesai → Insights. Screenshot halamannya.
  3. Di sini, tekan 📸 Impor screenshot → pilih kedua screenshot sekaligus (atau tempel dengan ⌘V / Ctrl+V).
  4. Cek angka yang terbaca. Kolom kuning = belum terbaca atau perlu dicek, isi/betulkan manual. Jam mulai Shopee wajib diisi (lihat tulisan "Waktu Mulai" di atas Tinjauan Data).
  5. Untuk Instagram, pilih sesi Shopee pasangannya (yang tayang bersamaan). Biasanya sudah ditebak otomatis.
  6. Tekan Simpan. Selesai — tim langsung melihat hasilnya di link dashboard.

Kalau sempat (melengkapi)

  1. Asal penonton Shopee: buka dashboard live Shopee (kotak oranye) → Sumber Menonton Livestream → ketik 6 persentasenya lewat tombol ✏️ Ubah Shopee di sesi itu.
  2. Produk terjual: di Tinjauan Data → Penjualan → Lihat Rincian → isi baris produk di ✏️ Ubah Shopee.
  3. Komentar live: salin komentar dari live (Shopee/IG), tempel di bagian Komentar live · dipilah JEV, tekan Pilah. Pertama kali, tempel dulu kunci JEV di ⚙️ Pengaturan.
  4. Aksi untuk live berikutnya: setelah angka & komentar lengkap, tekan 🎯 Minta rekomendasi JEV. JEV memilih masalah utama sesi + aksi konkretnya. Bahas hasilnya dengan host sebelum live berikutnya.

Lain-lain

  1. Di mana semua alat ini? Di tab 🛠 Admin (paling kanan). Tombol ✏️ Ubah di tab Per Sesi otomatis membawamu ke sini, dan tombol ← Kembali mengembalikanmu.
  2. Salah isi? Buka sesinya → ✏️ Ubah. Koreksi admin selalu menang atas data dari ekstensi.
  3. Data dobel / tidak penting? 🗂 Kelola data → centang → Hapus terpilih.
  4. Siapa mengubah apa? Riwayat perubahan mencatat apa dan jam berapa (password admin dipakai bersama, jadi nama tidak tercatat).
  5. Link penghitung: pastikan link beli di live IG memakai link di panel "Link penghitung IG → Shopee", bukan link Shopee langsung.
