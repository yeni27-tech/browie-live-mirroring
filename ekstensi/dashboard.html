browie Live Mirroring

📖 Selamat datang — ekstensi ini untuk apa?

Ekstensi ini membantu membuat laporan live mirroring browie: live yang tayang di Instagram dan Shopee sekaligus. Ekstensi bertugas mengambil data dari Seller Centre Shopee di Chrome ini. Laporannya bisa dilihat siapa saja lewat link dashboard online.

Langkah 1 — Sambungkan ke dashboard (sekali saja)

  1. Buka tab ⚙️ Pengaturan di atas.
  2. Isi Alamat dashboard dan Kode kirim yang diberikan Yeni.
  3. Tekan Simpan & cek. Kalau muncul tulisan "Tersambung", berarti sudah benar.

Langkah 2 — Mode intip (sekali saja, ±5 menit)

  1. Buka tab 🔎 Mode intip, ikuti 6 langkah di sana (membuka beberapa halaman Live Streaming di Seller Centre).
  2. Tekan ⬇︎ Unduh hasil intip, kirim file-nya ke Yeni.
  3. Ini supaya ekstensi bisa belajar di mana Shopee menyimpan angka live. Yang dicatat hanya nama kolom, bukan angka penjualan atau data pembeli.

Langkah 3 — Setiap selesai live (±3 menit)

  1. Screenshot Tinjauan Data sesi itu di Seller Centre (Live Streaming → klik sesi → Tinjauan Data).
  2. Screenshot Insights live di Instagram (profil → live yang selesai → Insights).
  3. Buka dashboard online (tombol di tab 📊 Ringkasan) → Masuk admin → 📸 Impor screenshot → pilih kedua screenshot.
  4. Cek angkanya. Kolom kuning = isi atau betulkan sendiri. Tekan Simpan. Selesai.

Pertanyaan yang sering muncul

  1. Apakah ekstensi ini mengubah sesuatu di Shopee? Tidak. Ekstensi hanya membaca, tidak menekan tombol, tidak mengubah toko.
  2. Laptop harus menyala terus? Tidak. Data hanya diambil saat Chrome ini terbuka dan Seller Centre masih login. Kalau mati, laporan tetap bisa dibuka dengan data terakhir.
  3. Muncul "Kode kirim salah"? Minta kode kirim terbaru ke Yeni, isi ulang di Pengaturan.
  4. Angka di dashboard salah? Buka dashboard online → Masuk admin → buka sesinya → ✏️ Ubah. Koreksi admin selalu dipakai.
  5. Mode / tampilan gelap? Pilih di pojok kanan atas: Ikut sistem, Terang, atau Gelap.
Buka dashboard online untuk mengisi / mengoreksi data ↗

Langkah untuk manager host (sekali saja)

  1. Buka Seller Centre Shopee di Chrome ini dan pastikan sudah login akun toko browie.
  2. Buka menu Live Streaming sampai terlihat daftar sesi live. Ganti tanggal atau halaman sekali.
  3. Klik satu sesi yang sudah selesai, buka Tinjauan Data. Ganti filter Status Pesanan sekali.
  4. Buka juga dashboard live (kotak oranye) untuk sesi itu, gulir sampai Sumber Menonton Livestream dan Profil Penonton.
  5. Kalau ada, buka halaman komentar atau rekaman sesi live.
  6. Kembali ke tab ini, tekan Unduh hasil intip, lalu kirim file-nya ke Yeni.

🧴 Si Henna (pet pemantau): di halaman Seller Centre, pojok kanan bawah ada tube henna alis kecil. Klik untuk melihat jumlah endpoint yang terekam, halaman yang dibuka, dan aktivitas terbaru; seret untuk memindahkan. Klik ikon ekstensi di toolbar saat berada di Seller Centre untuk menampilkan atau menyembunyikannya. Penarikan otomatis Shopee belum aktif, jadi sekarang pet hanya memantau mode intip.

Yang dicatat hanya alamat halaman, nama kolom, dan tipe datanya (angka/teks). Tidak ada angka penjualan, nama penonton, ID, atau password yang tersimpan. Mode intip tidak menekan tombol apa pun dan tidak mengirim apa pun; hasilnya hanya keluar saat tombol Unduh ditekan. Mati sendiri 8 November 2026.

Dashboard online tim

Isi alamat dashboard online dan kode kirim dari Yeni. Ekstensi memakai kode ini untuk menampilkan Ringkasan dan, nanti, mengirim data Shopee yang ditarik dari Seller Centre.

Cara mengisi data

  1. Instagram: buka dashboard online → Masuk admin → tab 🛠 Admin → 📸 Impor screenshot.
  2. Shopee: sementara diisi di dashboard online (+ Sesi Shopee). Setelah hasil mode intip diproses, ekstensi ini menariknya sendiri dari Seller Centre.
